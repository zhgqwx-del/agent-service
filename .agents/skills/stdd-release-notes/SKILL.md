# 版本差异与发布说明

1. 读 `AGENTS.md`，从任务或发布记录定位起止版本。限定到两次已知提交或标签时，由 root 用 `python3 -B scripts/git_range.py <基准引用> <候选引用>`。按日期汇总时采用项目迭代日历和可核对的合入记录，注明分支、时间窗和时区。
2. 对照候选差异、已合入的变更记录、规格和验收证据。把同一功能的提交归为一个可观察的变更条目，逐项核对发布范围内的修复、撤回和兼容变化。
3. 依据 `docs/stdd/templates/release.md` 起草说明，注明起止引用、用户影响、兼容与迁移、验收状态和待处理项。实际发布和正式验收引用 `docs/PROGRESS.md` 的对应版本记录。
