# 版本差异与发布说明

1. 读 `AGENTS.md`，从任务或发布记录定位起止引用，由 root 解析并固定两端 SHA。任务要求远端最新时，由 root 按当轮授权刷新已确认的引用。使用本地快照或刷新失败时，注明实际采用的引用、SHA 和刷新状态。版本比较由 root 用 `python3 -B scripts/git_range.py <基准SHA> <候选SHA>` 读取两端快照差异。按日期汇总时，以项目迭代日历和可核对的主线合入记录为准，注明分支、时间窗、时区和统计截止时刻。
2. 同时核对提交列表和文件差异，再对照变更记录、规格和验收证据。分叉或回退时仍比较两端快照，核对提交列表未体现的差异。把同一功能归为一个可观察的变更条目，按领域核对新增、修复、撤回、依赖和兼容变化，并写明筛选范围。
3. 依据 `docs/stdd/templates/release.md` 起草说明，注明范围、用户影响、兼容与迁移、验收状态和待处理项。分别标明候选版本和实际发布状态，实际发布和正式验收引用 `docs/PROGRESS.md` 的对应版本记录。仅分析时在答复中交付报告。需要保存时沿用项目的变更日志约定，发布操作按当轮授权执行。
