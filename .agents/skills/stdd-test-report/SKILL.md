# 生成验收记录

1. 读 `AGENTS.md`、`docs/engineering.md`、变更范围、确认后的规格和测试计划。按受影响的 AC 和现有证据选择适用的定向、回归及手工检查。
2. 由 root 按仓库约定运行适用检查，记录命令、退出状态、环境、数据及绑定受测字节的提交 SHA 或冻结证据。CI 证据绑定 run/attempt/SHA，真实模型请求须有具名预算。分别标明断言失败、环境阻塞和未执行，保留原失败与已过结果。
3. 手工验收按场景给出最小步骤、数据和预期。已经执行的由实际观察填结果，其他场景标为待验证。使用 `docs/stdd/templates/verification.md` 汇总自动与手工证据，引用仍相关的旧记录并写清对应版本。
4. 回报通过、失败、阻塞和待验证的场景及复跑入口。修复问题时沿对应的实现任务处理。
