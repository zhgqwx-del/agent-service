# 讨论与架构决策

每项变更在 `changes/<id>/change.md` 的「关联讨论与 ADR」下引用影响范围、方案或验收的资料，并说明本次影响。现行长期约定优先引用[设计专题](../design/README.md)、[运维手册](../operations/README.md)和[协作约定](../../AGENTS.md)。

## 何时单独记录

| 情况 | 记录位置 |
| --- | --- |
| 只影响本次变更，能在一次评审中决定的问题 | 写入本次 `change.md`，实现细节放在 `tasks.md` 或 `design.md` |
| 跨角色、团队或变更，需要多轮评审、比较备选方案，或需要持续跟踪证据 | 优先链接已有讨论或工单。需要单独文件时，可用[讨论模板](templates/discussion.md)记录问题、选项、结论和关联变更 |
| 会约束后续变更的架构、契约、数据或运维决策 | 优先在所属专题维护。需要独立记录时，可用 [ADR 模板](templates/adr.md)记录决策理由、后果和复查条件 |

已有 ADR 沿用其目录、编号和状态格式。新增记录按实际需要选定位置。历史提案按原状态引用，当前决定和待办以权威专题及 [PROGRESS](../PROGRESS.md) 为准。

## 链接与归档

从 `changes/<id>/` 归档到 `changes/archive/<id>/` 时保留编号，核对变更指向外部文件的相对链接，以及讨论、ADR 或索引指回变更的位置。
