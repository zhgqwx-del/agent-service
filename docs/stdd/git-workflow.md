# Git 工作方式

按 [AGENTS.md](../../AGENTS.md) 保留现有工作树和提交历史，默认在当前工作树接续。由 root 统一执行 Git 和网络操作。

## 开工

1. 用 `git status --short --branch` 查看实际工作树和暂存区，并在变更中记录分支、基线 SHA 与已有改动。任务涉及合入时，另记已确认的目标引用。
2. 任务涉及同步、选定分支或独立工作树时，核对当轮范围和真实基线，继承用户已有改动。

## 提交前

1. 按[开发与 CI 指南](../operations/development-and-ci-guide.md#6-分层验证路径)执行适用的本地门禁，记录实际结果并核对候选与受测内容的一致性。内容变化后复跑受影响的检查。
2. 提交、推送和发布遵循当轮授权。同范围已有授权可直接沿用。

## 触发 CI 后

经授权提交并触发现有 CI 后，核对适用的完整 CI 证据与最终候选 SHA 对应，记录实际 run/attempt/SHA 及门禁结果。交接记录实际候选、证据和待补门禁。必跑门禁失败或缺证据时，保留待验收状态。
