# CI-01 Docker 镜像摘要校验体验设计

## 适用范围

适用入口为 GitHub Actions 作业日志和该步骤的原生报告制品。

## 流程和状态

| 用户动作或状态 | 可观察结果 | 验收场景 |
| --- | --- | --- |
| 读取固定引用的 manifest 并校验本地镜像 | 报告记录两个已验证的摘要、本地 `.Id` 及其种类。 | `AC-CIIMAGE-001`、`AC-CIIMAGE-003` |
| 取证失败或身份不匹配 | 原步骤失败，报告和原生命令输出可定位触发条件。 | `AC-CIIMAGE-002`、`AC-CIIMAGE-003` |
| 两种镜像完成原生语法检查 | 报告绑定候选 SHA、run、attempt、命令与容器的结清。 | `AC-CIIMAGE-004` |

报告和验证路径见[规格](spec.md)及[验收计划](test-plan.md)。
